======================================================================
      HƯỚNG DẪN CÀI ĐẶT SHOPEE VOUCHER HUNTER TỪ MÁY TÍNH
======================================================================

BƯỚC 1: BẬT GỠ LỖI USB TRÊN ĐIỆN THOẠI ANDROID
----------------------------------------------------------------------
1. Vào 'Cài đặt' trên điện thoại -> 'Thông tin điện thoại' -> Nhấn liên tục 7 lần vào 'Số hiệu bản dựng' (Build Number) đến khi báo "Bạn đã là nhà phát triển".
2. Quay lại 'Cài đặt' -> 'Tùy chọn nhà phát triển' (Developer Options).
3. Bật mục 'Gỡ lỗi USB' (USB Debugging).
4. Bật mục 'Cài đặt qua USB' (Install via USB).
5. Cắm cáp kết nối điện thoại với máy tính.
   (Khi điện thoại hiện popup hỏi "Cho phép gỡ lỗi USB từ máy tính này?", hãy bấm "Cho phép" / "OK").

BƯỚC 2: CÀI ĐẶT TRÊN MÁY TÍNH
----------------------------------------------------------------------
1. Giải nén thư mục đã tải.
2. Mở file install_apk.bat.
3. Chương trình sẽ tự động nhận diện điện thoại và cài đặt file ShopeeHunter.apk!
CHÚ Ý: Bạn có thể tải file .apk và cài đặt như bình thường nhưng nhiều hệ điều hành sẽ chặn ứng dụng không rõ nguồn gốc nên khuyến khích bạn cài đặt qua máy tính để trải
nghiệm mượt mà hơn.

BƯỚC 3: CẤP QUYỀN TRÊN ĐIỆN THOẠI SAU KHI CÀI
----------------------------------------------------------------------
1. Mở ứng dụng, bấm nút 'Bật quyền' (Trợ năng / Accessibility).
2. Tìm ứng dụng 'Shopee Voucher Hunter' và bật lên.
3. Mở ứng dụng, bấm nút 'Bật Menu nổi' (để bảng điều khiển nổi đè lên app Shopee).
4. Tìm ứng dụng 'Shopee Voucher Hunter' và bật lên.
----------------------------------------------------------------------
BƯỚC 4: HƯỚNG DÃN SỬ DỤNG
1. Vào Shopee Voucher Hunter và bật menu nổi, sau đó vào app Shopee và đến màn hình thanh toán.
2. Kéo đến phần voucher và ấn CALIB để tinh chỉnh độ trễ.
3. Ấn TEST NOW để thử áp voucher.
4. Nếu đã cảm thấy ổn, vào app chỉnh từ chế độ TEST sang chế độ LIVE để ứng dụng tự động áp voucher và đặt hàng.
